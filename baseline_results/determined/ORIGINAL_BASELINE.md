## Повторение

Повторный длительный прогон сейчас не требуется. Для нового эксперимента:
открыть notebook и выполнить Restart Kernel → Run All. Для запуска только
industrial задать `RUN_DATASETS = ("industrial",)`; остальные настройки по
умолчанию уже соответствуют оригиналу.

Проверка готовых результатов без повторного извлечения, из корня проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 verify_original_baseline.py
```

Это baseline оригинального детерминированного извлечения из сохранённого HTML:
со встроенными профилями сайтов и опциональным штатным фильтром запроса.
Живой браузер, конфигурации из БД и LLM fallback в него не входят. В industrial
один отсутствующий HTML остаётся отмечен в manifest и не оценивается.
Режим query оценивается относительно всех GT-товаров страницы, поэтому фильтр
релевантности снижает recall.

Предыдущие результаты B1/B2 сохранены в
`.artifacts/notebook-original/20261002T112944Z-legacy-results.zip` относительно
корня проекта. B1/B2/B3 доступны только как явно выбираемые дополнительные методы.
